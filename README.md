# Zalău City Website

A small, responsive single-page website about **Zalău** — the capital of Sălaj County in Transylvania, Romania.

Built with plain HTML, CSS, and vanilla JavaScript (no build step, no dependencies).

## Features

- Responsive layout with a mobile navigation menu
- Hero section, history timeline, attractions cards, animated stat counters, and visitor info
- Smooth scroll and reveal-on-scroll animations

## Run locally

Because it's a static site, you can either open `index.html` directly, or serve it (recommended, so paths and the fetch-free JS behave like production):

```bash
# Python 3
python -m http.server 8000
```

Then open <http://localhost:8000> in your browser.
